## Описание
  Данный проект демонстрирует работу базовых операций с банковскими счетами, включая создание, просмотр, обновление и удаление счетов, а так же проведены транзакции между ними. Архитектура построена по многослойному принципу с контроллерами для обработки HTTP-запросов, сервисным слоем для бизнес логики и репозиториями для работы с БД. Для хранения данных используется SQL-база, а взаимодействие с ней организованно через JPA/Hibernate.
Проект был создан в рамках практики Backend-разработки на Java.

## Функциональность
- Узнать баланс по ID пользователя;
- Снятие заданной суммы с баланса пользователя;
- Пополнение баланса на заданную сумму;
- Отобразить список операций за выбранный период;
- Перевести заданную сумму другому пользователю.

## Установка
### Клонировать репозиторий
```
git clone https://github.com/DmitryLkT/bank_app_rest_api.git
```
### Перейти в директорию
```
cd bank_app_rest_api
```
### Собрать и запустить

```
mvn exec:java -Dexec.mainClass="org.LukDT.main"
```
